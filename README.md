# つけ回し管理

キャバクラのつけ回し（卓ローテーション）管理をiPadで行うためのスタンドアロンWebアプリ。
個人利用専用。サーバ不要、ローカルストレージにのみ保存。

## 使い方

1. `index.html` を iPad の Safari で開く。
2. （任意）共有ボタン →「ホーム画面に追加」でアプリ風に使用可能。
3. 右上「＋女の子」で女の子を登録。
4. 「＋卓」で卓を追加。卓をタップして詳細を開く。
5. お客様名を入力し、回転1〜3の枠から女の子を選択。
6. 進行中の回転は「時間通り終了」「+1/2/5分」「+遅延入力」ボタンで終了処理。
   - 遅延を入れると次回転の持ち時間にプラスされ、最終時間も延びる。
7. 詳細画面・左サイドの女の子をタップでドリンク加算（卓が選択されている時、卓に紐付く）。
8. 退店ボタンで会計確認。

## 表示ルール

- 卓は丸（円）で表示。経過とともに残時間・終了予定時刻を表示。残り時間がマイナスになると赤く点滅。
- 女の子サイドバーで、選択中の卓に既についている女の子は **黄色** 枠。
- ピッカーで同じお客様に2回付けようとすると **赤色** で警告し、選択不可。

## 設定（⚙）

- セット料金（円）
- ドリンク単価（円）
- 回転数（既定 3）
- 基本時間は上部セレクタで 50 / 60 分切替

## 構成

- `index.html` / `styles.css` / `app.js` / `manifest.json`
- 永続化: ブラウザの localStorage (`tsuke-mawashi-v1`)
- 外部依存なし、オフライン動作

## 注意

- 個人利用専用。App Store 配信は想定していない。
- データはブラウザのローカル領域にのみ保存されるため、Safari の履歴/データ削除で消える可能性あり。
